# Accensa App

The `accensa-app` repository houses the Merchant Back-Office and documentation for the entire x402 protocol on Stellar. It is much more than a frontend; it is a comprehensive dashboard that acts as the control center for merchants.

## Features

- **Merchant Deployments:** Manage Soroban smart contract deployments seamlessly.
- **Authentication:** Handles SEP-10 authentication to ensure secure merchant sessions.
- **Reconciliation:** Provides real-time tracking and reconciliation of payment streams and settled vaults.
- **Reference Implementation:** Serves as a perfect reference implementation for developers wanting to build complex UI components that interact natively with Stellar smart contracts.
